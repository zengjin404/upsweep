# 识别规则目录

本目录用于存放外部识别规则 JSON。**阶段 0 尚未实现规则引擎，因此这里暂时没有规则文件。**

计划文件（阶段 3 定义）：

```text
rules/
├── directories.json          # 目录名称/位置特征
├── filenames.json            # 文件名、版本号、扩展名特征
├── protected-paths.json      # 受保护路径
└── software-rules.json       # 软件特定关联规则
```

规则要求：

- 只包含声明式数据，不包含可执行脚本。
- 每条规则包含 ID、名称、适用文件类型、匹配方式、风险影响、说明、版本。
- 加载时校验；无效规则跳过并提示；保留默认规则回退。
- 外部规则不得绕过硬编码的安全保护边界（系统目录、主安装目录、路径规范化、重解析点检查、占用检查、清理前二次校验）。
- 规则只能提高或降低候选的**可信度**，不能单独触发删除；最终操作仍需用户确认与后端复核。
